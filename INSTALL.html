安装与使用说明

跑图工坊内置 Python 和运行依赖，使用时不需要安装 Python 或 Photoshop。请保留发行包中的说明、第三方许可证及对应源码材料。

Windows：解压即用

  1. 下载 Windows ZIP，选择“全部解压”，保存到本机可读写的文件夹。
  2. 在解压后的根目录双击 跑图工坊.exe，由启动入口检查运行环境并打开软件。
  3. 保留整个目录，不能只复制 EXE。PaotuStudio 文件夹中的程序、_internal 目录及其余随包文件都是运行所需内容。
  4. 完成离线授权后使用。

当前主程序未完成 Windows 数字签名，系统可能提示发布者未知或出现 SmartScreen。请先确认文件来自本下载站的 GitHub Release，并校验摘要；来源无法确认、摘要不一致或安全软件提示实际威胁时，请停止打开并联系软件提供者，不要关闭全局防护。

如果出现 Python DLL 或运行库载入错误，不需要自行安装 Python。双击根目录的 运行环境诊断.exe；它不依赖 Python，会在工具旁边生成 PaotuStudio-启动诊断-日期时间-编号.txt，目录不能写入时会提示临时保存位置。请将文件私下发给软件提供者，用于定位缺失文件、权限或系统依赖；其中含本机路径，不要公开上传。该工具不读取授权码、表格或素材，不主动联网，不修改原程序与授权资料。

Mac：打开 DMG

  1. 下载与芯片匹配的 DMG，双击打开。
  2. 将“跑图工坊.app”拖入 Applications（应用程序）。
  3. 从应用程序目录启动“跑图工坊”。
  4. 完成离线授权后使用。

当前应用使用本地 ad-hoc 签名，DMG 未签名，尚未完成 Apple Developer ID 签名和公证。因此不能保证首次打开没有系统安全提示。

如果出现“Apple 无法验证是否包含恶意软件”等提示：

  1. 先确认下载来源和 SHA-256；关闭提示。
  2. 打开“系统设置 → 隐私与安全性”，找到刚刚阻止“跑图工坊”运行的提示。
  3. 仅在确认来源后，为这一个应用选择“仍要打开”，按系统提示确认。

不同 macOS 的文字和位置可能稍有差异，以系统当前提示为准。如果没有该选项，电脑可能受组织设备策略管理，请联系管理员。请勿为此关闭 Gatekeeper、关闭系统完整性保护或降低全局安全设置。系统声称检测到实际恶意软件、文件损坏或摘要不匹配时，不应直接放行。

Apple：安全地打开 Mac 上的 App

离线激活与续期

  1. 在软件授权窗口点击“复制申请码”。
  2. 将这台电脑生成的申请码通过你已有的联系渠道发给软件提供者。
  3. 收到激活码后，完整粘贴至激活码输入框，点击“激活 / 续期”。
  4. 确认软件显示已授权及有效期，再继续使用。

申请码与激活码是不同内容。激活码绑定对应的电脑安装；不要把另一台电脑的激活码粘贴到本机。更换电脑或安装状态变化时，应重新生成申请码。授权文件导入、导出是备用方式，不需要为正常激活手动编辑文件。

软件正常使用时无需连接授权服务器；授权期限由软件提供者签发。到期需取得新的激活码续期。本网站不收集申请码，也不提供授权签发或授权管理功能。请勿在公开 Issue 中贴申请码、激活码或业务素材。

第一次跑图

  1. 选择 PSD / PSB 模板或模板目录；多模板时，让表格的“类型”等匹配字段与模板文件名对应。
  2. 添加 Excel 需求表，可添加多个文件并读取其中符合要求的工作表。
  3. 添加素材文件夹；素材在不同位置时，可添加多个路径。素材子文件夹和文件名按模板图层、表格约定对应。
  4. 选择输出目录。默认 JPG 白底、质量 100%，也可选择 PNG。
  5. 先运行检查并预览，解决缺素材、字段不匹配等问题，再批量导出。

以 SKU 作为商品标识的表格，导出文件名取 SKU；商品名称表格按对应名称处理。模板“类型”用于选择模板与输出子文件夹，和输出文件名是不同字段。图片、网盘链接和参考资料不会自动转成可用的跑图需求。

文案里的 / 表示换行，例如 高纯度/咖啡因。角标可按约定填写 清润淡纹（角标-32） 或 饱满细腻（角标-*）。文字效果仍应结合具体模板预览；字体需要在使用电脑上具备合法可用的授权和安装状态，软件不随包分发你的商业字体。

首次使用建议选择少量商品检查结果，再处理整份表格。外接素材盘应在整个生成过程中保持连接。

校验下载文件

每个 Release 附有 SHA256SUMS.txt，其中是文件的校验值，不是激活码，也不需要用软件打开。摘要一致表示文件与发布记录一致，不等于系统安全认证。

Mac 终端：

shasum -a 256 ~/Downloads/PaotuStudio-macos-arm64.dmg

Intel 版请将文件名改为 PaotuStudio-macos-x86_64.dmg。

Windows PowerShell：

Get-FileHash "$env:USERPROFILE\Downloads\PaotuStudio-windows-x64.zip" -Algorithm SHA256

将输出与同一 Release 的记录逐字核对。
