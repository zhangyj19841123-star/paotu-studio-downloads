Windows 便携版如何打开？+

下载 ZIP 后先完整解压，再双击根目录的“跑图工坊.exe”。请保留整个文件夹，不要只复制 EXE，也不要直接在压缩包内运行。如仍有运行库错误，请用旁边的“运行环境诊断.exe”生成说明，私下发给软件提供者；无需自行安装 Python。

目标系统为 Windows 7 SP1 x64 及后续 64 位版本。Windows 7 需要支持 AddDllDirectory 的系统更新（KB2533623 或后续替代更新）；不包含 32 位版本。当前程序未完成 Windows 数字签名，系统可能显示发布者提示。请核对下载来源与校验值后再决定是否运行。各系统仍需实际测试。

Mac 提示“无法验证”或“未打开”，怎么办？+

打开 DMG，将“跑图工坊”拖到“应用程序”，再从“应用程序”打开。首次使用可能遇到 Apple 无法验证的提示，这是当前版本尚未完成 Developer ID 签名和公证所致。

确认来自本下载页后，前往“系统设置 → 隐私与安全性”，在该应用的拦截提示旁选择“仍要打开”，再确认打开。较旧系统的名称可能为“系统偏好设置 → 安全性与隐私”。按钮通常在尝试打开后显示，受管理的电脑可能需要管理员处理。仅允许该应用，不要关闭系统的全局安全保护。

如何获得离线授权？+

打开软件的授权窗口，复制本机申请码，发给软件提供者。收到对应激活码后粘贴，点击“激活 / 续期”。也可按窗口说明使用申请文件和授权文件。

授权与当前电脑及安装状态绑定，并有有效期。激活码与申请码不同；换机或到期时请联系软件提供者。本站不生成授权码，也不提供授权管理。

还需要安装 Python 或 Photoshop 吗？+

不需要。下载包已包含 Python 与运行依赖，软件直接读取 PSD / PSB。将需求表、模板与产品素材准备在本地或已连接的素材硬盘中，再在软件中选择对应路径。

文字样式来自模板。若目标电脑缺少模板使用的字体，可能需要安装你有合法使用权的对应字体，并检查实际出图效果。
