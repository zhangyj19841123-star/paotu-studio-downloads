# 跑图工坊公开发行 · 2026-11-10

- Mac Apple Silicon 0.7.9，ARM64 DMG，macOS 12.3 及以上，Apple Silicon。
- Windows 0.7.10，x64 便携 ZIP，Windows 10 1809 及以上或 Windows 11 x64。

- Windows 0.7.10 修复旧版有效授权在升级时被误判的问题，保留原 Windows 账户及授权目录即可继承。
- Excel 支持局部字体颜色、单元格真实换行和显式大小字，普通斜杠原样显示。
- 扩展横排段落框及已支持的高位深 PSD/PSB 和调整图层，同名素材按项目上下文匹配。

公开包使用电脑已安装的字体。请合法安装模板所用字体，并在预检后确认预览。

Mac 打开 DMG 后将应用拖入「应用程序」。Windows 完整解压后运行最外层的 `跑图工坊.exe`。Mac 已在 M5 / macOS 26.3.1 复验，应用使用 ad-hoc 签名且未公证。Windows 成品在 Wine 验证，未签名，Windows 实体机仍待复验。
